# NONCHALANT FC · Оценка составов

Telegram Mini App, где игроки FC Mobile отправляют скриншот состава на бесплатную оценку или платят (Стандарт / Экспресс), чтобы гарантированно попасть в ваши видео на TikTok. Есть админ-панель, приоритетная очередь, ручная проверка платежей и уведомления в Telegram. Весь интерфейс, бот и сообщения на русском.

- **Фронтенд:** React + TypeScript + Tailwind CSS v4
- **Бэкенд:** Node.js (без фреймворков, единственная зависимость `pg`)
- **База данных:** PostgreSQL (схема в `server/migrations/`, применяется автоматически при запуске)
- **Хранение скриншотов:** диск сервера или Supabase Storage (приватный bucket)
- **Один процесс** отдаёт API, приложение (`/`) и админку (`/admin`).

## Что вам нужно предоставить

| Что | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` | **@BotFather** в Telegram → `/newbot` |
| `ADMIN_TELEGRAM_IDS` | Ваш числовой Telegram ID. Отправьте боту команду `/id` или напишите @userinfobot. Юзернейм вместо числа не подходит |
| `DATABASE_URL` | Любой PostgreSQL 13+ (Supabase, Neon, Railway, Render или свой) |
| `APP_URL` | Публичный **HTTPS**-адрес вашего приложения (Telegram требует HTTPS) |
| `APP_SECRET` | Случайная строка: `openssl rand -hex 32` |
| `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` | *Необязательно.* Только если хотите хранить скриншоты в Supabase |

Полный список с комментариями: [`.env.example`](.env.example).

## Запуск на своём компьютере

Нужны Node 22+ и база PostgreSQL.

```bash
cp .env.example .env          # заполните DATABASE_URL, ADMIN_TELEGRAM_IDS и поставьте DEV_AUTH_BYPASS=true
npm run install:all
npm run build                 # собирает web/dist
npm start                     # http://localhost:3000 (миграции применяются сами)
```

Telegram для локального просмотра не нужен: при `DEV_AUTH_BYPASS=true` (в production игнорируется) откройте
`http://localhost:3000/?dev=111` как обычный пользователь и `http://localhost:3000/admin?dev=<ваш админский ID>` как админ.

## Размещение в интернете

### 1. Создайте бота
1. В @BotFather отправьте `/newbot` и скопируйте токен.
2. Больше ничего в BotFather делать не нужно. При запуске сервер сам задаст команды бота и кнопку меню «Оценка составов», ведущую на `APP_URL`.

### 2. Разместите приложение (любой вариант)

**Railway / Render / Fly.io (проще всего, используется готовый `Dockerfile`)**
1. Загрузите папку проекта в репозиторий GitHub и создайте новый сервис из него (Docker).
2. Добавьте базу PostgreSQL и укажите `DATABASE_URL` (и `DATABASE_SSL=true`, если провайдер требует TLS).
3. Укажите остальные переменные из `.env.example`. `APP_URL` — это HTTPS-адрес, который выдаст платформа.
4. **Скриншоты:** подключите постоянный том к `/app/uploads` либо используйте Supabase Storage (создайте *приватный* bucket `squads`, задайте `SUPABASE_URL` и `SUPABASE_SERVICE_KEY`). Без этого загруженные скриншоты пропадут при перезапуске контейнера.
5. Запустите. Адрес проверки работоспособности: `/api/health`.

**Свой VPS**
```bash
git clone <репозиторий> && cd nonchalant-fc
cp .env.example .env && nano .env
docker build -t nonchalant-fc .
docker run -d --name nfc --restart unless-stopped --env-file .env -p 3000:3000 \
  -v nfc-uploads:/app/uploads nonchalant-fc
```
Поставьте перед приложением Caddy или nginx для HTTPS, например Caddyfile: `your-domain.example { reverse_proxy localhost:3000 }`.

Без Docker: `npm run install:all && npm run build && NODE_ENV=production npm start` (запускайте через systemd или pm2).

### 3. Первый запуск
1. Откройте бота в Telegram, отправьте `/start` и нажмите **Открыть приложение**.
2. Не знаете свой числовой ID? Запустите приложение с любым временным числом в `ADMIN_TELEGRAM_IDS`, отправьте боту `/id`, подставьте полученное число и перезапустите.
3. Отправьте боту `/admin` со своего аккаунта, чтобы получить кнопку панели (`APP_URL/admin`). Остальным бот ответит «Недоступно.».
4. В **Админка → Цены** задайте цену Стандарта и Экспресса, валюту и **инструкцию по оплате** (текст, который видит игрок после заказа: карта, USDT-кошелёк, PayPal и т. д.). Текст по умолчанию — заглушка.

При long polling (по умолчанию) запускайте ровно один экземпляр. Для нескольких экземпляров включите `TELEGRAM_USE_WEBHOOK=true` и задайте `TELEGRAM_WEBHOOK_SECRET`.

## Как это работает

**Бесплатно:** игрок указывает никнейм, UID и скриншот → создаётся заказ `NFC-XXXXXX` со статусом «Отправлено», самым низким приоритетом в очереди и без гарантии видео.

**Платно (Стандарт / Экспресс):** игрок выбирает тариф и загружает состав → заказ создаётся как «Ожидает оплаты», цена берётся из базы на сервере (клиент не может её подменить) → игрок видит вашу инструкцию по оплате и нажимает «Я оплатил» (можно указать данные платежа). Это лишь отправляет заказ вам на проверку. **Платёж считается оплаченным только после того, как админ подтвердит его** в панели или кнопками «Подтвердить платёж / Отклонить», которые бот присылает админам. После подтверждения заказ попадает в очередь. Отклонённый платёж можно отправить повторно. Бесплатный заказ можно улучшить до Стандарта или Экспресса.

**Очередь:** Экспресс → Стандарт → Бесплатные, внутри уровня по времени создания. В **Админка → Очередь** любой заказ можно поднять в начало, выше или ниже.

**Жизненный цикл (управляет админ):** Оценка: В очереди → Оценивается → Оценено. Публикация: добавьте ссылку на TikTok и отметьте «Опубликовано», игрок увидит кнопку «Смотреть в TikTok» во вкладке «Заказы». Заявку можно отклонить или удалить (при отклонении игрок получает уведомление).

**Зал славы:** пятая вкладка с подиумом топ‑3 и рейтингом опубликованных составов (никнейм, оценка, тариф, ссылка на видео). UID и данные пользователей не показываются. Данные отдаёт `GET /api/hall`. На главной показываются счётчики «оценено» и «попало в видео», а оценка в заказе показывается анимированным кольцом с уровнем (Элита 90+, Про 80+, Крепкий состав 70+, Растущий 50+). Анимации отключаются при `prefers-reduced-motion`.

**Анимации:** заставка при запуске, пружинное появление блоков при прокрутке, конфетти при первом открытии заказа с опубликованным видео, линия прогресса заказа. Все отключаются при `prefers-reduced-motion`.

**Достижения и мелочи:** во вкладке «Заказы» шесть достижений (Дебют, Оценён, Серия, Экспресс, В кадре, Элита), считаются из заказов игрока. На главной бегущая лента лучших оценок, у главной кнопки блик, при отправке по скриншоту едет сканирующая линия, карточка лучшего состава наклоняется за пальцем.

**Тема:** кнопка с солнцем/луной на главной и в админке переключает белую и чёрную темы. По умолчанию белая, выбор запоминается на устройстве и красит шапку Telegram.

**Уведомления в Telegram:** заявка получена, платёж подтверждён или не подтверждён, оценка началась, оценка готова, видео опубликовано. Если пользователь заблокировал бота, заказ это не ломает, ошибка просто записывается.

## Безопасность

- Данные `initData` от Telegram проверяются на сервере (HMAC-SHA256 с токеном бота, проверка свежести, сравнение за постоянное время). Единственный идентификатор — Telegram ID, паролей нет.
- Админ-API и панель требуют, чтобы проверенный Telegram ID входил в `ADMIN_TELEGRAM_IDS`; проверка на каждый запрос.
- Пользователь видит только свои заказы и скриншоты, чужие возвращают 404.
- Загрузки: только JPG/PNG/WEBP, тип определяется по содержимому файла, лимит размера, случайные имена, приватное хранение и выдача через защищённые ссылки.
- Статусы платежей меняются только админскими серверными методами со строгими переходами; повторные нажатия защищены ключом идемпотентности; есть лимит заказов на пользователя.
- Токен бота, адрес БД и ключ Supabase есть только в переменных окружения сервера. Включены строгий CSP и защитные заголовки.

## Тесты

```bash
# нужен Postgres, где пользователь может создавать базы
TEST_PG_ADMIN_URL=postgres://postgres@127.0.0.1:5432/postgres npm test
```
19 сквозных тестов запускают настоящий сервер на временной базе с подставным Telegram API. Они проверяют initData, бесплатные и платные заказы, защиту от двойных нажатий, изоляцию чужих заказов, админские маршруты, подтверждение и отклонение платежей, приоритеты и ручной порядок очереди, уведомления, смену цен, кнопки бота и заблокировавших бота пользователей.

```

server/test/         сквозные тесты
web/src/app/         приложение (Главная, Отправка, В видео, Зал славы, Заказы)
web/src/admin/       админка (Обзор, Заказы, Очередь, Цены)
Dockerfile           образ для production
```
